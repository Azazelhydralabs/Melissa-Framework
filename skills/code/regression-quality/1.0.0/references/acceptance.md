# Geliştirme kabulü

Testlerin gerçekten keşfedildiğini, doğru davranışı sınadığını ve yanlış uygulamayı yakaladığını göster.

- Sıfır testin pass olması
- Tekrarda değişen test kimliği veya flake
- Stale raporun final source'a taşınması

Pozitif fixture ile karşı örneğin sonuçları ayrılmalıdır. Bu testler ürün/otonom model veya alan uzmanlığı kabulü değildir. Kaynak sürümü, helper hash'i ve ham çıktı korunur.
