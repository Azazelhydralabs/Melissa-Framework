# Geliştirme kabulü

Eyleme dönük gerçek kusuru doğru kaynak ve karşı örnekle göster; tarayıcı etiketini kesin bulgu yapma.

- Kanıtsız severity
- Scanner çıktısının kesin zafiyet sanılması
- Eski kaynakta bulunan hatanın final sürüme yazılması

Pozitif fixture ile karşı örneğin sonuçları ayrılmalıdır. Bu testler ürün/otonom model veya alan uzmanlığı kabulü değildir. Kaynak sürümü, helper hash'i ve ham çıktı korunur.
