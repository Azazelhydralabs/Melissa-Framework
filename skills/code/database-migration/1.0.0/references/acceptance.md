# Geliştirme kabulü

Şema değişiminin veri doğruluğunu, yarış davranışını ve kesinti sonrası durumunu koru.

- Eksik/sırası bozuk migration
- Unique/foreign key ihlali
- Kesintide kısmi veri

Pozitif fixture ile karşı örneğin sonuçları ayrılmalıdır. Bu testler ürün/otonom model veya alan uzmanlığı kabulü değildir. Kaynak sürümü, helper hash'i ve ham çıktı korunur.
