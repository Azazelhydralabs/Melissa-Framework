# Geliştirme kabulü

Değişikliğin doğru pakete, sembole, tüketiciye ve teste ulaşmasını sağla.

- Yanlış repository veya aynı adlı komşu pakete yönlendirme
- Üretilen dosyanın kaynak sanılması
- Eski referans grafının güncel kanıt olması

Pozitif fixture ile karşı örneğin sonuçları ayrılmalıdır. Bu testler ürün/otonom model veya alan uzmanlığı kabulü değildir. Kaynak sürümü, helper hash'i ve ham çıktı korunur.
