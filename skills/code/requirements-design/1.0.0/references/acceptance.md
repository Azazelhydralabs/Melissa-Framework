# Geliştirme kabulü

Kullanıcının gerçek davranış isteğini sınanabilir tasarım ve kabul ilişkisine dönüştür.

- Metin şemaya uyuyor diye davranışın doğrulanmış sayılması
- Gereksinimlerin testlerle ilişkisiz kalması
- Gereksiz uzman veya yetki eklenmesi

Pozitif fixture ile karşı örneğin sonuçları ayrılmalıdır. Bu testler ürün/otonom model veya alan uzmanlığı kabulü değildir. Kaynak sürümü, helper hash'i ve ham çıktı korunur.
