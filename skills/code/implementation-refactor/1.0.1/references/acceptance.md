# Geliştirme kabulü

En küçük doğru değişikliği gerçek tüketicilerde uygula ve kullanıcı çalışmasını koru.

- Scope dışı dosya değişimi
- Stale preimage
- Test veya assertion silinerek başarı

Pozitif fixture ile karşı örneğin sonuçları ayrılmalıdır. Bu testler ürün/otonom model veya alan uzmanlığı kabulü değildir. Kaynak sürümü, helper hash'i ve ham çıktı korunur.
