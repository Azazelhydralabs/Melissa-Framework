# Geliştirme kabulü

Hatayı yeniden üret, rakip hipotezleri ayır ve karşı deneyle kök nedeni daralt.

- Yanlış binary veya stale frame
- El ile geliştirici müdahalesinin otonom onarım diye sunulması
- Asıl senaryonun yeniden denenmemesi

Pozitif fixture ile karşı örneğin sonuçları ayrılmalıdır. Bu testler ürün/otonom model veya alan uzmanlığı kabulü değildir. Kaynak sürümü, helper hash'i ve ham çıktı korunur.
