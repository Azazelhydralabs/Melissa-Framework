# Geliştirme kabulü

Kullanıcının gerçek ekran akışını durum, odak, klavye ve responsive davranışla tamamla.

- Sadece görsele bakıp form akışını kabul etmek
- Klavye/focus hatalarının atlanması
- Eksik browser kanıtı

Pozitif fixture ile karşı örneğin sonuçları ayrılmalıdır. Bu testler ürün/otonom model veya alan uzmanlığı kabulü değildir. Kaynak sürümü, helper hash'i ve ham çıktı korunur.
