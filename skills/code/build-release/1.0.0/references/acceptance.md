# Geliştirme kabulü

Tekrarlanabilir toolchain/lock/input zincirinden gerçek çalışan artifact üretimini kanıtla.

- Yanlış artifact hash'i
- Sıcak cache başarısının temiz build sanılması
- Çalıştırılmamış paketin release kabulü

Pozitif fixture ile karşı örneğin sonuçları ayrılmalıdır. Bu testler ürün/otonom model veya alan uzmanlığı kabulü değildir. Kaynak sürümü, helper hash'i ve ham çıktı korunur.
